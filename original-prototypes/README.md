# Original prototypes (reference only)

These three static HTML files are the original single-file prototypes the
`apps/shop`, `apps/prodairy`, and `apps/retinah` React apps were built from.
They are kept here for historical reference only — **they are not run, built,
or deployed**, and none of the fixes or features added since (the shop+product
data model, the sales heatmap, the interactive dashboard filters, real shop
data, etc.) exist in them.

| File | Superseded by |
|---|---|
| `shop-app.html` | [`apps/shop`](../apps/shop) |
| `prodairy-dashboard.html` | [`apps/prodairy`](../apps/prodairy) |
| `retinah-workspace.html` | [`apps/retinah`](../apps/retinah) |

Safe to delete once nobody needs to compare against the original design.
